1) 요구사항 분석
요구사항 분석은 데이터 모델링이나 시스템 개발을 위한 첫 번째 단계로, 사용자와의 면담, 설문조사, 업무 문서 분석 등을 동해 사용자의 요구를 파악하고 정리하는 과정이다.
이 단계에서는 시스템이 제공해야 할 기능이 무엇인지, 어떤 데이터를 저장하고 관리해야 하는지, 데이터 간에는 어떤 관계가 있는
지를 분석하여 이후 데이터 모델링과 시스템 설계의 기초 자료로 활용한다.




```
1. 요구 사항 분석(DATA)

2. 개넘적 데이터 모델링 ERD (Entity-Relationship Diagram)

3. 논리적, 물리적 모델링(Logical, Physical Data Modeling)

4. 데이터 베이스에 테이블 생성
```

현실 세계의 업무 대상과 사용자의 요구사항을 파악하고 분석하여 데이터베이스의 목적과 필요한 데이터를 정의하는 단계이다.
- 데이터베이스 사용자 식별
- 데이터베이스 사용 목적 및 범위 식별
- 사용자 요구사항 수집 및 명세



2) 개념적 설계 단계
개념적 설계는 요구사항 분석 결과를 바탕으로 실제 데이터베이스의 테이블 구조를 설계하기 전에, 업무에서 필요한 데이터와 데이
터 간의 관계를 추상적인 형태로 표현하는 단계이다.

이 단계에서는 다음과 같은 작업을 수행한다.
· 업무에 필요한 주요 개체(Entity) 식별
· 각 개체가 가지는 속성(Attribute) 정의
· 개체 간의 관계(Relationship) 설정
· 각 개체를 식별하기 위한 식별자(Identifier) 정의
· 개체 간 관계의 카디널리티(1:1, 1:N, N:M) 및 참여 조건 정의
· 분석한 결과를 ERD(Entity Relationship Diagram) 등으로 표현
